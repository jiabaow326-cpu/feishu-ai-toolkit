# ChatGPT Chrome 六個實戰工具與使用方式

文章正文中的六組可複製 Prompt，涵蓋訂閱報帳、餐廳空位比較、App Store 送審、退款草稿、海報設計與公開資料整理。

分類：輸出風格、HTML 與瀏覽器任務

## 工具原文

[開啟完整原文](../toolkits/chatgpt-chrome.md) · [下載／檢視純文字](https://raw.githubusercontent.com/jiabaow326-cpu/shen-one-san-ai-toolkit/main/toolkits/chatgpt-chrome.md)

提示詞、程式碼與設定保留來源原文。要複製提示詞時，選取該項完整區塊；若原文含巢狀程式碼區塊，請使用純文字連結，避免漏掉後半段。

## 何時使用

需要讀取已登入網站、跨頁搬資料或進行多步網頁操作，並結合插件、Record & Replay 或長任務工具時。

## 前置需求

- 來源中的 Chrome 擴充功能及對應 AI 環境；依案例另需 Gmail 插件、Google Sheets、App Store Connect、Creative Production 或長任務模式。實際支援依目前產品介面與帳戶而定。

## 使用方法

1. 依文章安裝並選擇日常使用的 Chrome profile，登入相關服務。複製所需案例的完整 blockquote Prompt，替換括號中的應用名稱、目標、地點、日期或設計文案。按原文保留最終送出、送審與支付確認給人。

原文最後一組使用『/目标』措辭，原 Prompt 保留；實際指令請依工具介面確認。原文對反爬限制的描述是案例敘述，操作仍須遵守網站授權與限制。來源圖片含登入授權網址，未收錄圖片或其網址。
