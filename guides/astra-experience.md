# Astra 實作體驗包

兩份原始繁體中文 Prompt，建立產品 Landing Page 或互動 3D 扭蛋機，附正式 Goal token 預算與操作驗收。

分類：工具選擇與模型分工

## 工具原文

[開啟完整原文](../toolkits/astra-experience.md) · [下載／檢視純文字](https://raw.githubusercontent.com/jiabaow326-cpu/shen-one-san-ai-toolkit/main/toolkits/astra-experience.md)

提示詞、程式碼與設定保留來源原文。要複製提示詞時，選取該項完整區塊；若原文含巢狀程式碼區塊，請使用純文字連結，避免漏掉後半段。

## 何時使用

想用小作品體驗 GPT-6 Astra 的設計、空間、動畫與互動能力時。

## 前置需求

- 支援 GPT-6 Astra 與正式 Goal 的 Codex 桌面 app 一般持續任務。
- 使用空白專案，環境需能寫檔、執行程式；一般 codex exec 與 ephemeral 對話不適用 Goal 前置條件。
- Goal token 預算是達限收尾控制，實際可超過，不是精準美元費用上限。

## 使用方法

1. 建立空白專案並選擇 GPT-6 Astra。
2. 複製完整題目，填入【】資料；選填欄位可填「由你設計」。
3. 確認 Goal token 預算；先驗證系統已建立 Goal，再開始製作。
4. 依完成後開啟方式實測導覽、表單或抽取／揭曉／再玩以及手機版。
